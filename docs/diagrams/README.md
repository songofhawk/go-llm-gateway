# 教程插图源文件

这些图表示请求、资源和状态之间的精确关系，使用 Mermaid 编写。第 0、1 课在正文中直接嵌入 Mermaid 代码块，配色配置使用图内 YAML frontmatter 的 `config` 字段，由阅读器直接显示。其余课程通过 `docs/assets` 中的 SVG 显示插图。

每张图在这里保留 `.mmd` 源文件。正文直接嵌入 Mermaid 的图要同步更新正文代码块和对应源文件；引用 SVG 的课程要同步更新源图与导出图，避免图文含义不一致。

## 可选：导出 SVG

直接显示 Mermaid 的教程不需要这一步。需要独立图片，或维护使用 SVG 的课程时，再执行以下命令。

安装 Node.js 和 Mermaid CLI（当前验证版本 11.12.0），然后在项目根目录执行：

```sh
npm install -g @mermaid-js/mermaid-cli@11.12.0
bash scripts/render-diagrams.sh
```

也可通过 `MMDC` 指向已有安装，不必全局安装。需要指定 Chrome 时，将浏览器配置 JSON 的路径传给 `PUPPETEER_CONFIG`；格式见 [Mermaid CLI 文档](https://github.com/mermaid-js/mermaid-cli)。这些是文档构建依赖，不会加入 Go 模块或参与网关运行。

## 绘图约定

- 一张图围绕一个问题，长标签放到图后的解释里。
- 较长的概念说明应配对应的关系图、时序图或结构图，图中的名词与正文保持一致，并用一两句提示说明如何读图。
- 第 0 课使用统一的柔和配色：青绿表示客户端或输入，蓝色表示 HTTP 服务或响应，紫色表示 handler、代理及 context，暖金表示上游连接或配置，珊瑚表示错误和取消。正文中的源码名与图中标签保持对应。
- 同时用标签、箭头和区域表达角色，避免只靠颜色传递含义；浅色底配深色字，保持文字可读。
- 流程图的箭头表示标注的处理或数据流向；时序图从上往下表示时间。
- 教学示意数值明确标注；第 6 步的协程快照数值来自已有实测报告。
- 不把 200、202、任务完成、结果入库当成同一个状态。
- 不用概念插图代替实际边界：取消不保证撤销供应商计算，fallback 不增加容量。
- 优先维护精确关系图；文生图只适合不依赖文字、数量和箭头精度的情境插画，目前这些教程无需额外情境插画。
