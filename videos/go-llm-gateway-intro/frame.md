# Visual direction

把抽象的网关讲成一条可追踪的请求旅程：青绿色表示正在前进的数据，紫色表示模型选择，琥珀色表示等待、限制或需谨慎的边界。大面积深色留出对比度，流程图占主画面，短标题锚定左上方，底部用小号课程路径标记进度。视觉克制、清晰、像一本会动的工程笔记。
